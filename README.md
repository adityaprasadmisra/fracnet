## 1. Project Overview

FracNet is a deep learning-based approach for fractional Doppler channel estimation in Orthogonal Time Frequency Space (OTFS) communication systems.

In high-mobility communication environments, Doppler shifts may not align with integer Doppler bins. This fractional Doppler effect can cause channel estimation errors and inter-Doppler interference.

This project implements a super-resolution-based neural network that learns to refine coarse channel estimates generated by a conventional MATLAB channel estimation pipeline.

The objective is to improve channel estimation accuracy by combining conventional signal processing with deep learning.

## 2. Research Foundation

This implementation is based on the paper:

**"OTFS Fractional Doppler Channel Estimation Method Based on Super-Resolution Networks"**

Authors: Cheng Guo and Lidong Zhu  
Conference: IEEE Wireless Communications and Networking Conference (WCNC), 2024.

The proposed approach uses super-resolution and residual learning concepts to recover channel characteristics from coarse estimates.

This repository contains an adapted PyTorch implementation. It should not be considered an exact reproduction of every architectural detail of the original paper.

## 3. System Architecture

The project combines MATLAB-based OTFS simulation and PyTorch-based deep learning.

```text
             OTFS Transmitter
                    |
                    v
             OTFS Modulation
                    |
                    v
          Fractional Doppler Channel
                    |
                    v
             OTFS Demodulation
                    |
                    v
          Received Pilot Observations
                    |
                    v
       MATLAB Coarse Channel Estimator
                    |
                    v
                 H_est
                    |
                    v
             +-------------+
             |   SRNet     |
             | Super-      |
             | Resolution  |
             +-------------+
                    |
                    v
             +-------------+
             |   STNet     |
             | Residual    |
             | Refinement  |
             +-------------+
                    |
                    v
           Refined Channel Estimate
                    |
                    v
              Evaluation
```

The neural network learns the mapping:

- **Input:** Coarse channel estimate (`H_est`)
- **Target:** Clean channel response (`Yclean`)
- **Output:** Refined channel estimate

The current implementation uses residual learning:

\[
\hat{Y}=H_{\mathrm{est}}+\Delta H
\]

where \(\Delta H\) is the learned correction.

## 4. Neural Network Architecture

### SRNet — Super-Resolution Network

SRNet extracts features and performs the initial super-resolution transformation.

Current implementation:

- Input channels: 8
- First convolution: 8 → 64
- Second convolution: 64 → 32
- Fully connected layers for feature transformation
- Output channels: 8

### STNet — Structure Transformation Network

STNet refines the features using residual learning.

Current implementation:

- Initial convolution: 8 → 64
- Three residual blocks
- Batch normalization
- ReLU activation
- Final convolution: 64 → 8
- Outputs a learned correction

### FracNet

FracNet combines SRNet and STNet and adds the predicted correction to the original input.

Total parameters: approximately 3.21 million.

## 6. Dataset

The dataset is generated using the MATLAB Revision 20 channel estimation pipeline.

Dataset file:

`dataset/fracnet_train.mat`

Current dataset size: **100 samples**

### Dataset Variables

| Variable | Description |
|---|---|
| `H_est` | Coarse channel estimates |
| `Yclean` | Clean received DD-domain channel response |
| `Ynoisy` | Noisy received observations |
| `Xpilot` | Known pilot grids |
| `SNR_dB` | SNR values |
| `noise_variance` | Noise variance |
| `path_delay` | Path delay information |
| `path_doppler` | Fractional Doppler information |
| `path_gain` | Complex path gains |
| `dopplerGrid` | Doppler search grid |
| `delayGrid` | Delay search grid |

### Input and Output Dimensions

| Property | Shape |
|---|---|
| MATLAB complex input | 100 × 4 × 12 × 12 |
| MATLAB complex target | 100 × 4 × 12 × 12 |
| PyTorch input | 100 × 8 × 12 × 12 |
| PyTorch target | 100 × 8 × 12 × 12 |

Real and imaginary components are represented as separate channels.

### Requirements

- Python 3.10
- PyTorch
- NumPy
- SciPy

## 9. Training

Run the training script:

```bash

```

The training pipeline uses:

- Adam optimizer
- Mean Squared Error loss
- Training/validation/test split
- Model checkpointing

The best checkpoint is saved in:

## 12. Preliminary Results

The current 100-sample experiment produced the following test results:

| Method | Test NMSE | NMSE (dB) |
|---|---:|---:|
| MATLAB coarse estimator | 0.002160 | -26.65 dB |
| Original FracNet | 0.008031 | -20.95 dB |
| Calibrated FracNet | 0.002161 | -26.65 dB |

**Important:** These are preliminary results from a small test set containing 10 samples. The current experiments do not demonstrate an improvement over the MATLAB coarse estimator.

A larger dataset and more extensive evaluation are required before drawing final performance conclusions.
